# Mission Reflection

The cloud platform that impressed me the most is AWS because it has many different services. I learned that AWS, Azure, and GCP all provide similar services such as virtual machines, storage, databases, networking, and security. They are different because each platform has its own strengths and features.

Business requirements are important when choosing a cloud platform. For example, if a company already uses Microsoft products like Windows Server and Microsoft 365, Azure would be a good choice. For a company that focuses on AI and Machine Learning, GCP can be a good choice. AWS can also be useful for companies that need many different cloud services.

From acting as a Cloud Solutions Consultant, I learned that choosing a cloud provider is not only about choosing the most popular one. We need to understand what the client needs first. We should consider the company's budget, technology, type of application, and future growth before choosing a cloud platform.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added research about AWS, Azure, and GCP, comparison tables, client recommendations, and my Linux investigation using KillerCoda. I also learned how to organize my work using Markdown and GitHub. My Checkpoint 7 also helped me understand how a Linux server can be moved to cloud services such as Amazon EC2, Azure Virtual Machines, and Google Compute Engine.

Overall, this activity helped me understand the differences between AWS, Azure, and GCP. It also taught me that the best cloud platform depends on the needs of the company and not just on which provider is the most popular.
