# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform, or GCP, is Google's cloud computing platform. It provides services for computing, storage, networking, databases, AI, and other applications.

## Global Infrastructure

Google Cloud has regions and zones around the world. These help companies run their applications in different locations.

## Cloud Management Console

Google Cloud Console is a website where users can manage their Google Cloud services.

## Four (4) Core Services

1. Compute Engine – runs virtual machines.
2. Cloud Storage – stores files and data.
3. Google Cloud VPC – provides networking.
4. Google Kubernetes Engine – manages Kubernetes applications.

## Three (3) Advantages

1. It is strong in AI and Machine Learning.
2. It has strong Kubernetes support.
3. It has a global infrastructure.

## Typical Enterprise Use Cases

Google Cloud can be used for AI, Machine Learning, data analysis, websites, applications, and Kubernetes.
