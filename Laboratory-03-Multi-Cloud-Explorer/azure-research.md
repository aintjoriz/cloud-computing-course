# Microsoft Azure

## Brief Overview

Microsoft Azure is a cloud platform from Microsoft. It provides services for applications, storage, databases, networking, and other IT needs.

## Global Infrastructure

Azure has data centers and regions around the world. This allows companies to run applications in different locations.

## Cloud Management Console

The Azure Portal is a website where users can create and manage Azure resources.

## Four (4) Core Services

  1. Azure Virtual Machines – runs virtual machines.
  2. Azure Blob Storage – stores files and data.
  3. Azure Virtual Network – provides networking.
  4. Microsoft Entra ID – manages identity and access.

## Three (3) Advantages

  1. It works well with Microsoft products.
  2. It supports many enterprise services.
  3. It has a global infrastructure.

## Typical Enterprise Use Cases

Azure can be used for Windows servers, business applications, databases, storage, and Microsoft-based systems.
